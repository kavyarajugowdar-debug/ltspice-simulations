# CMOS Inverter Simulation

## Aim

To simulate a CMOS inverter using LTspice and observe the relationship between the input and output voltages.

## Software Used

- LTspice

## Circuit

The CMOS inverter consists of:
- PMOS transistor
- NMOS transistor
- DC supply
- Input voltage source

## Simulation

The input voltage is applied to the gates of both MOSFETs.

When the input is LOW:
- PMOS is ON
- NMOS is OFF
- Output is HIGH

When the input is HIGH:
- PMOS is OFF
- NMOS is ON
- Output is LOW

Therefore, the output is the inverse of the input.

## Expected Result

The output waveform should be the inverted form of the input waveform.

## Learning Outcome

Through this simulation, I learned the basic operation of a CMOS inverter and how to observe its input and output waveforms using LTspice.
